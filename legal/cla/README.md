# Contributor licence agreements

Orden uses the Harmony Contributor License Agreements, version 1.0 (4 July 2011), in the licence version. You keep the copyright in what you contribute and grant a licence.

| File | Who signs it |
| --- | --- |
| [HA-CLA-I.md](HA-CLA-I.md) | A person contributing in their own name |
| [HA-CLA-E.md](HA-CLA-E.md) | A company or other legal entity |

How to sign is described in [CONTRIBUTING.md](../../CONTRIBUTING.md).

## Source

The text comes from the official templates at https://www.harmonyagreements.org/agreements.html (`ha-cla-i-v1.odt` and `ha-cla-e-v1.odt`). The clauses are unchanged. Only the template's blanks are filled and its options chosen, as listed below. The templates are licensed under the Creative Commons Attribution 3.0 Unported License.

## How the template was filled in

| Template field | Value |
| --- | --- |
| `[PROJECT_NAME]` | Orden, a software project managed by Emil Vinu |
| `[SUBMISSION_INSTRUCTIONS]` | https://github.com/lxorb/orden/blob/main/CONTRIBUTING.md |
| `[NONOWNER_INSTRUCTIONS]` | the section "Work you do not own" of the same file |
| Section 2.2, `[or Your Affiliates]` | left out for individuals, included for entities |
| Section 2.3, outbound licence | Option Five (any licence, and always also the licence in use for Orden on the day of the contribution). Options One to Four are removed, as the template intends. |
| Section 2.3, optional sentence on media licences | left out, because Option Five already covers media |
| `[JURISDICTION]` in section 6.1 | Switzerland |
| Signature block, "Us" | Emil Vinu, maintainer of Orden |

The template has no clause naming a court, so none was added.

"We" and "Us" are Emil Vinu. If Orden moves to a company, the rights can be assigned to it under section 6.3, which binds the company to the same agreement.
